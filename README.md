- AI Chatbot Project

- Overview

This project is an AI-powered chatbot developed using Python and Natural Language Processing (NLP) techniques. The chatbot can understand user queries and generate relevant responses through an interactive interface.

-Features

* Interactive chatbot interface
* Natural Language Processing (NLP)
* User-friendly design
* Real-time responses
* Chat history support

-Technologies Used

* Python
* NLP
* Machine Learning
* Tkinter / GUI
* Flask (if used)

-Project Structure

* app.py
* gui.py
* ai_chatbot_final.py
* templates/
* history.txt

-How to Run

1. Clone the repository
2. Install required libraries
3. Run:
   python app.py
